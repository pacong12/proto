# よくある質問（FAQ）

Goton でのトークンの取引、ローンチ、管理に関するよくある質問への回答を見つけてください。

---

## 一般的な質問

### Goton とは？

Goton は、**Robinhood Chain**（L2）と **Arc Network**（Circle ステーブルコイン L1）の両方をサポートする、分散型でノンカストディアルな仮想通貨ローンチパッドです。誰もが固定供給のトークンをローンチし、ライブチャートで取引し、永久にロックされた流動性を持つ公平なローンチに参加できます。

### 開発者はラグプルや流動性の引き抜きができますか？

**いいえ。** Goton で作成された流動性プールのポジションは、オープンソースのスマートコントラクト `LiquidityLocker.sol` に直接ミントされ、永久にロックされます。アンロック関数も、バックドアも、管理者の出金キーもありません。

### どのウォレットがサポートされていますか？

Goton は、以下を含むすべての標準的な Ethereum 互換 Web3 ウォレットをサポートします。

- MetaMask
- Coinbase Wallet
- Rabby Wallet
- Rainbow Wallet
- WalletConnect / Reown 互換のモバイルウォレット

Goton はウォレットを接続するだけです。メールやソーシャルログインはないため、アプリがあなたのキーを保持することは決してありません。

## 取引とスワップ

### なぜ取引が失敗したのですか？

取引が失敗する主な理由は 2 つです。

1. **スリッページ超過**: 高いボラティリティの間、クリックからブロック確定までの間に、価格が設定したスリッページの割合を超えて変化しました。取引設定でスリッページを上げてください（例: 1% から 2%）。
2. **ガス残高不足**: ネットワークの実行手数料を支払うため、常にネイティブのガストークン（Robinhood では ETH、Arc では USDC）の少額残高を保っておいてください。

### On Curve と Graduated の違いは？

- **On Curve (v2)**: トークンは現在、数学的なボンディングカーブ上で取引されています。トークンが買われるにつれて価格が上がります。
- **Graduated**: Robinhood Chain では、カーブが 4.2 ETH の目標に達し、市場が永久にロックされた Uniswap v4 プールへ移行しました。Arc Network では、トークンはローンチ時から Uniswap v4 プールで取引され、時価総額が約 45,000 ドルを超えるとプール内で卒業します。

### 目標価格で売買できますか？

はい。**Limit** と **TP / SL** タブは、時価総額が目標に達すると自動的に約定する注文を置き、いつでもキャンセルできます。[指値・テイクプロフィット・ストップロス注文](/ja/protocol/advanced-orders) を参照してください。

### Explore と Memestock の違いは？

Explore はすべてのトークンを掲載します。Memestock は、クリエイターが購入してポジションの大半をまだ保有している、書かれたテーゼ付きのローンチのみを、直近の取引順に掲載します。[フィード、コール、Memestock、フォロー](/ja/protocol/social) を参照してください。

### 売却の制限はありますか？

**決してありません。** ユーザーはいつでもトークンを売却できます。Goton がホルダーにロックアップ、売却クールダウン、転送凍結を課すことは決してありません。

## トークン作成

### トークンのローンチにはいくらかかりますか？

プロトコルのデプロイ手数料は、Robinhood Chain では **0.0005 ETH**、Arc Network では **無料（0 USDC）**（最低 4.50 USDC の初期事前購入が必要）です。これはスマートコントラクトのデプロイ、トークンのミント、初期流動性のロックをカバーします。

### 後からトークンを追加でミントできますか？

**いいえ。** Goton で作成される各トークンは、ちょうど **1,000,000,000 トークン**（10 億）の不変・固定供給量を持ちます。コントラクトにミント関数はありません。

### クリエイターはどのように手数料を得ますか？

各トークンの手数料と税はオンチェーンで分配されます。**Robinhood Chain ではクリエイターの取り分に 70%、Arc では 80%**、残りはプロトコルへ。クリエイターは公開取引が始まる前に一度だけ、その取り分を自分自身、ホルダー、buyback-and-burn の間で分割できます。[クリエイター手数料と報酬](/ja/protocol/fees-and-burns) を参照してください。累積した手数料は**プロフィール**ページで請求します。

## ネットワークとサポート

### Goton はどのネットワークを使いますか？

Goton は、**Robinhood Chain**（Chain ID: `4663`）と **Arc Network**（Chain ID: `5042`）をサポートするマルチチェーンプロトコルとして稼働します。

### どこでヘルプを得られますか？

コミュニティの支援、ディスカッション、アップデートについては、公式コミュニティチャンネルに参加するか、[検証済みスマートコントラクト](/integration/contracts) をご確認ください。
