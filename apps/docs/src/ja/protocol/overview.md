# Goton とは？

**Goton** は、**Robinhood Chain (Chain ID: 4663)** および **Arc Network (Chain ID: 5042)** 上に構築された、コミュニティ優先のノンカストディアル型トークンローンチパッドです。

複雑な金融ハードルや隠れた先行販売、突然の流動性持ち逃げ（_Rug Pull_）のリスクなしに、誰でも安全・公平にトークンを発行・取引・発見できる環境を提供します。

---

## なぜ Goton を選ぶのか？

従来のローンチパッドでユーザーが直面してきた重大なリスクを Goton は解決します：

1. **持ち逃げ（Rug Pull）の完全防止**: すべての流動性ポジションはオープンソースコントラクト (`LiquidityLocker.sol`) に永久ロックされます。開発者も管理者も流動性を引き出す権限を持ちません。
2. **高速スナイパーボットへの対抗**: ローンチ直後の数ブロックにおいて、1注文あたりの購入上限（最大5.5%）とウォレット保有上限（最大5.0%）を設けることで、コミュニティ参加者の公平性を確保します。
3. **完全固定供給量**: トークン総供給量は **1,000,000,000 トークン**（10億枚）に永久固定されており、後から新規発行（ミント）することは不可能です。

## 2つのローンチモデル

| モデル                            | 仕組み                                                                                                                                                                                 | 最適なプロジェクト                                           |
| :-------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------- |
| **Robinhood: ボンディングカーブ** | 価格曲線（$x \cdot y = k$）上で取引されます。約7億1,430万トークン（71.43%）がカーブで販売され、4.2 ETHに達すると残り約2億8,570万トークンを含むロック済みUniswap v4プールへ卒業します。 | 段階的な価格発見を行いたいコミュニティトークンやMemeコイン。 |
| **Arc: ローンチ時からUniswap v4** | 全供給量が最初のブロックから片側流動性としてUniswap v4プールに配置されます（初期評価額 約$2,480）。時価総額が約$45,000を超えるとプール内で卒業し、移行はありません。                   | 最初のブロックからUniswapで取引したいトークン。              |
