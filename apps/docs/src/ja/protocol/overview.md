# Proto とは？

**Proto** は、**Robinhood Chain (Chain ID: 4663)** および **Arc Network (Chain ID: 5042)** 上に構築された、コミュニティ優先のノンカストディアル型トークンローンチパッドです。

複雑な金融ハードルや隠れた先行販売、突然の流動性持ち逃げ（_Rug Pull_）のリスクなしに、誰でも安全・公平にトークンを発行・取引・発見できる環境を提供します。

---

## なぜ Proto を選ぶのか？

従来のローンチパッドでユーザーが直面してきた重大なリスクを Proto は解決します：

1. **持ち逃げ（Rug Pull）の完全防止**: すべての流動性ポジションはオープンソースコントラクト (`LiquidityLocker.sol`) に永久ロックされます。開発者も管理者も流動性を引き出す権限を持ちません。
2. **高速スナイパーボットへの対抗**: ローンチ直後の数ブロックにおいて、1注文あたりの購入上限（最大5.5%）とウォレット保有上限（最大5.0%）を設けることで、コミュニティ参加者の公平性を確保します。
3. **完全固定供給量**: トークン総供給量は **1,000,000,000 トークン**（10億枚）に永久固定されており、後から新規発行（ミント）することは不可能です。

## 2つのローンチモデル

| モデル                    | 仕組み                                                                                                                                      | 最適なプロジェクト                                           |
| :------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------ | :----------------------------------------------------------- |
| **v1 ダイレクトプール**   | 初日からUniswap V3プールに直接ローンチし、100%の非開発者保有分を即座に永久ロックします。                                                    | 最初から最大のDEX流動性深度を必要とするプロジェクト。        |
| **v2 ボンディングカーブ** | アルゴリズムによる価格曲線（$x \cdot y = k$）から開始し、目標金額（Robinhoodで4.2 ETH、Arcで8,400 USDC）調達後に自動でUniswapへ卒業します。 | 段階的な価格発見を行いたいコミュニティトークンやMemeコイン。 |
