# プロフィールとアイデンティティ

Goton のすべてのウォレットには公開プロフィールと組み込みの**ペンネーム**があり、最初の取引から名前とページを持てます — 登録は不要です。ウォレットを接続していれば、いつでもプロフィールをカスタマイズできます。

---

## あなたのペンネーム

ウォレットが現れた瞬間、Goton はそのアドレスから導いた決定論的なユーザー名を付けます。形容詞、素材、アーキタイプに、アドレス由来の短いタグを加えたもので、たとえば **AeroBrassGriffin#79c8** です。そこから、すべて同じウォレットを指す 3 つの形が生まれます。

- **表示名** — `AeroBrassGriffin#79c8`
- **ハンドル** — `@AeroBrassGriffin#79c8`
- **スラッグ** — `aerobrassgriffin-79c8`（URL に安全な形）

アドレスから導かれるため、ペンネームは**決して変わらず**、アプリ全体で同じです。あなたの [リファラルリンク](/ja/protocol/referrals) もこれを使います。

---

## プロフィール URL

プロフィールは、いずれも同じウォレットに解決する複数の同等なパスから開けます。

- `/u/<アドレス>`、`/profile/<アドレス>`、`/user/<アドレス>`、`/@<アドレス>`
- `/<ユーザー名>` — スラッグ。例: `/aerobrassgriffin-79c8`

アドレスの URL はきれいな `/<ユーザー名>` 形へ書き換えられます。入力した名前、スラッグ、ハンドルはアドレスへ解決されるため、名前を共有することはアドレスを共有するのと同じように機能します。

---

## プロフィールの編集

**自分の**プロフィール（ウォレット接続時）では、**Edit Profile** で公開クリエイターのアイデンティティをカスタマイズできます。

| 項目                 | 備考                                           |
| :------------------- | :--------------------------------------------- |
| **カバーバナー**     | デバイスからアップロードした画像               |
| **プロフィール写真** | デバイスからアップロードしたアバター           |
| **表示名**           | 最大 32 文字。公開上はペンネームを上書きします |
| **自己紹介**         | 短い説明 — 戦略、あなたのアルファ、何でも      |
| **X（Twitter）**     | あなたのハンドル                               |
| **Telegram**         | あなたのハンドル                               |

アップロードした画像は IPFS に保存され、プロフィールの残りはウォレット向けに保存されます。ソーシャルデータを**消去**して、カスタムフィールドを空にしペンネームへ戻すこともできます。

---

## プロフィールが表示するもの

すべてのプロフィール — あなたのものでも誰のものでも — は、そのウォレットの活動を 1 か所にまとめます。

- **[クリエイターの評判](/ja/protocol/reputation)** — ローンチ実績。
- **[ポートフォリオ](/ja/protocol/portfolio)** — パフォーマンスと現在の保有。
- **Posts & Calls** — [フィード](/ja/protocol/social) での活動。
- **Created Tokens** — そのウォレットがローンチしたトークン。
- **[ホルダー配当とベスティング](/ja/protocol/dividends-and-vesting)** — 請求可能な報酬（自分のプロフィール）。
- **[友達を招待](/ja/protocol/referrals)** — その招待リンク（自分のプロフィール）。

---

## 注記

- プロフィールは**公開**で、オンチェーンの活動に、あなたが設定した任意のフィールドを加えて構築されます。チェーンとあなた自身の編集が提供する以上のものは公開しません。
- アカウント、メール、パスワードは存在しません。あなたのウォレットが*そのまま*あなたのアイデンティティです。
