# ホルダー配当とベスティング

プロフィールの **Dividends** タブは、2 種類のオンチェーン報酬を回収する場所です。保有トークンの**ホルダー手数料分配の配当**と、時間とともにアンロックされる割り当ての**ベスティング中のトークン**です。どちらもウォレットへ直接請求します。

---

## ホルダー配当

一部のトークンはローンチ時に **Holder Fee Sharing** を有効にします。これらのトークンでは、取引手数料の一部が、クリエイターだけでなく**すべてのホルダーへ比例配分**で蓄積されます。

Dividends タブでは次が表示されます。

- **Total claimable** — 蓄積された報酬。通貨ごとに表示（Robinhood では ETH / WETH、Arc では USDC）。
- **トークンごとのエントリ** — 手数料を分配する保有トークンそれぞれと、あなたを待つ金額。
- **Claim all** — すべてのトークンの配当を一度に回収するか、行から 1 つのトークンを請求します。

トークンが取引される限り報酬は蓄積し続け、請求すると蓄積分がウォレットへ掃き出されます。トークンがここに表示されるのは、クリエイターが Holder Fee Sharing を有効にした場合のみです。手数料の分配の設定方法は [クリエイター手数料と報酬](/ja/protocol/fees-and-burns) を参照してください。

---

## ベスティング

トークンが時間とともにアンロックされる割り当て（クリエイターや貢献者の割り当てなど）を付与する場合、その**ベスティングのスケジュール**が同じタブにトークンごとに表示されます。

| 項目                      | 意味                                     |
| :------------------------ | :--------------------------------------- |
| **Total（まだロック中）** | まだアンロックされていないトークン       |
| **Claimed**               | すでにウォレットへ解放したトークン       |
| **Claimable**             | 今すぐ解放できるアンロック済みトークン   |
| **Cliff ends**            | これより前は何もアンロックされない日付   |
| **Fully unlocked**        | 割り当て全体のベスティングが完了する日付 |

スケジュールには **cliff**（その日付までは何も解放されない）があり、その後は完全にベスティングするまで段階的にアンロックされます。ベスティングのポジションでは 2 つのアクションが利用できます。

- **Claim tokens** — 今請求できるアンロック済みトークンをウォレットへ解放します。
- **Claim dividends** — そのベスティングのポジションが獲得したホルダー手数料分配の配当を回収します。

---

## 注記

- ここでのすべては**オンチェーン**です。請求はウォレットのトランザクションであり、ベスティングと手数料分配のロジックはトークンのコントラクトに存在し、あなたの報酬をリダイレクトできる管理者はいません。
- このタブは、請求可能な金額とベスティングを**自分の**プロフィールでのみ表示します（ウォレットを接続してください）。金額はトークンが取引され、アンロックが cliff を過ぎるにつれて更新されます。
