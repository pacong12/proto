# ポートフォリオ・ダッシュボード

プロフィールには **Portfolio** タブがあり、取引の状況 — 実現・未実現の損益、勝率、現在保有する各トークン — をまとめます。すべてあなたのオンチェーン取引から計算されます。

---

## サマリー

Portfolio タブの上部:

| 指標           | 意味                                           |
| :------------- | :--------------------------------------------- |
| **Total PnL**  | 全ポジションの実現 + 未実現損益の合計（USD）   |
| **Realized**   | 売却によってすでに確定した損益                 |
| **Unrealized** | まだ保有するトークンの、現在価格での含み損益   |
| **Win rate**   | クローズしたポジションのうち利益で終わった割合 |

利益は緑、損失は赤で表示され、口座の状態が一目で読み取れます。

---

## 保有

サマリーの下に、**オープンポジション**のテーブルが現在保有する各トークンを掲載します。

- **資産** — トークン。
- **残高** — 保有量。
- **価格** — トークンの現在の USD 価格。
- **価値** — 保有の現在の USD 価値。
- **アクション** — トークンの **trade** ページへ移動するか、**PnL カード**を開いてポジションを共有します（共有リンクが招待コードをどう運ぶかは [友達を招待・リファラル](/ja/protocol/referrals) を参照）。

別のリストは**クローズしたポジション** — 完全に売却したトークン — をそれぞれの結果とともに表示します。

まだ何も保有していない場合、タブはトークンの探索と取引へ誘導します。

---

## 注記

- すべては**インデックス済みのオンチェーン取引**から導かれ、手動の台帳ではありません。ウォレットを接続すれば履歴が自動で埋まります。
- アクティビティのリストは最新の取引の 1 ページ分なので、1 ページが埋まっていても生涯の合計を表すわけではありません。
- 自分のプロフィールで共有・取引のショートカットが見えるのはあなただけです。訪問者は、開いた任意のウォレットについて同じパフォーマンス要約と保有を見ます。
