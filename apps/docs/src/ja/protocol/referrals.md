# 友達を招待・リファラル

すべてのプロフィールには、個人の招待リンク付きの**友達を招待**カードがあります。誰かがあなたのリンクから Goton を開いてウォレットを接続すると、そのウォレットはあなたにクレジットされます。アトリビューションは**オフチェーンかつファーストタッチ（first-touch）**なので、ガスも署名も不要です。

---

## あなたの招待リンク

自分のプロフィールを開き、**友達を招待**カードを見つけます。表示されるもの:

- **招待リンク** — `https://goton.fun/?ref=<あなたのユーザー名>`。ウォレットのユーザー名（例: `aerobrassgriffin-79c8`）を使います。ウォレットアドレスでも機能しますが、ユーザー名の方が読みやすく共有しやすいだけです。
- **Referred** — これまでに招待したウォレット数。
- **リンクをコピー** — リンクをクリップボードにコピーします。

同じ `?ref=` コードは、Goton 内から何かを共有するたびに自動的に付きます。[リンクはどこへ伝わるか](#リンクはどこへ伝わるか) を参照してください。

---

## アトリビューションの仕組み

- **ファーストタッチ。** 訪問者が最初に開いた招待リンクがカウントされます。ウォレットを接続するまでブラウザに記憶され、後のリンクは**上書きしません**。
- **1 つのウォレット、1 回。** 訪問者がウォレットを接続すると、そのウォレットはあなたのリンクに一度だけ紐付きます。再接続や、その後に別のリンクを開いても何も変わりません。
- **自己リファラル不可。** 自分のリンクを開いて自分のウォレットを接続しても、何も記録されません。
- **ユーザー名またはアドレス。** ユーザー名の `?ref=` は記録前にリファラーのウォレットへ解決されます。取引やローンチをしたことのないリファラーは名前で解決できない場合があり、その際はアドレス形式のリンクが最も確実です。

アトリビューションがファーストタッチかつオフチェーンのため、悪用者ができる最悪のことは、見た目上のカウントを水増しすることだけです。このカウントは現時点では情報提供であり、紐づくオンチェーンの報酬はまだありません。

---

## リンクはどこへ伝わるか

あなたのリファラルコードは、アプリ内から共有するリンクに追加されるため、活動を共有することがそのままネットワークの拡大になります。

| アクション                          | 共有される内容                                           |
| :---------------------------------- | :------------------------------------------------------- |
| **プロフィールを共有**              | 接続中ウォレットの `?ref` を伴ったプロフィールへのリンク |
| **PnL カードを共有**                | `?ref` 付きの `/pnl/…` カードリンク                      |
| **X で共有**（トークン / 取引から） | `?ref` 付きのトークンページのリンク                      |
| **コール**や投稿を共有              | `?ref` 付きの `/post/…` リンク                           |

いずれの場合もコードは**接続中**のウォレット（共有する本人）のものなので、他人のプロフィールを共有してもあなたにクレジットされます。

## FAQ

**今、リファラルで何か得られますか？** まだです。カウントは今のところ見た目上のものです。報酬が導入される際には、アトリビューションは署名付きのオンチェーントリガー（被紹介者の最初のローンチや取引など）へ移行する見込みです。

**誰に紹介されたかを変更できますか？** いいえ。ウォレットが接続された時点でファーストタッチは恒久的です。

**リンクはユーザー名を使いますが、安定していますか？** ユーザー名はウォレットアドレスから導かれるため、決して変わりません。
