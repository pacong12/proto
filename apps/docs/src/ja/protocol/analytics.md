# プロトコルアナリティクス

**Analytics** ページは、Goton での活動 — どれだけ取引されているか、いくつトークンがローンチされているか、プロトコルが生み出す手数料 — を、現在いるネットワークについてネットワーク全体のライブビューで示します。

---

## メインチャート

1 つのインタラクティブなチャートが、**直近 24 時間**の 1 つの指標をバケットで描きます。指標を切り替えます。

| 指標         | 描く内容                           |
| :----------- | :--------------------------------- |
| **Volume**   | 時系列の取引量                     |
| **Launches** | 時系列のローンチされたトークン     |
| **Fees**     | 時系列の生成されたプロトコル手数料 |

**滑らかなエリア**表示と**バー**表示を切り替えられます。すべては**アクティブなネットワーク**（Robinhood または Arc）に限定されます。もう一方のチェーンの数値を見るにはヘッダーからネットワークを切り替えます。

---

## 主要な統計

チャートの下に、サマリーカードがネットワークの合計を表示します。含まれるもの:

- **総取引量** — ネットワークの全体的な取引量。
- **ローンチされたトークン総数** — いくつトークンが作成されたか。
- **税 / 手数料の見積り** — 生成された手数料の見積り。
- **Buyback** — プロトコルの買い戻し活動（ある場合）。

**トップトークン**のリストはトークンを時価総額順に並べ、マクロビューから特定トークンの trade ページへ直接移動できます。

---

## 注記

- 数値は**オンチェーンデータ**から構築され、新しいブロックが処理されるにつれて更新されます。同じ数値を自分のツールで使いたいですか？ [公開 API](/integration/api) にあります。
- アナリティクスは**ネットワークごと**です。ページは常にヘッダーに表示されたチェーンを反映し、その範囲の注記で示します。
- 数値はインデクサー由来で、新しいブロックが処理されるにつれて更新されます。24 時間のウィンドウはカレンダー上の 1 日ではなく、移動するビューです。
