# クリエイターの評判

すべてのプロフィールは、クリエイターの**ローンチ実績** — 何をリリースしてきたかの、オンチェーン由来の手早い要約 — を表示します。トレーダーが、背後にあるウォレットの履歴から新しいトークンを判断するのに役立ちます。

---

## 表示される内容

クリエイターのプロフィールにある評判カードは、そのウォレットがローンチした各トークンを要約します。

| 指標                 | 意味                                                                   |
| :------------------- | :--------------------------------------------------------------------- |
| **Launches**         | そのウォレットが作成したトークン数                                     |
| **Graduated**        | そのうちボンディングカーブを完了し Uniswap v4 プールへ移行した数       |
| **Active**           | まだ稼働し取引されている数                                             |
| **Graduation rate**  | Graduated ÷ Launches（パーセント）                                     |
| **Total market cap** | クリエイターのトークンの合計 USD 時価総額                              |
| **Top token**        | 時価総額が最大のクリエイターのトークン（名称、シンボル、時価総額付き） |

---

## 計算方法

- 数値は**オンチェーンデータ**（そのウォレットがデプロイしたトークンと現在の市場状態）から構築され、クリエイターが入力するものではありません。
- **ここに自己申告はありません。** クリエイターはこれらの数値を編集できず、アドレスに紐づくローンチを反映します。
- 何かを開発していますか？ 同じ数値は [公開 API](/integration/api) から利用できます。

---

## トレーダーとしての読み方

- 複数のローンチにわたる高い**卒業率**は、単一の卒業トークンよりも強いシグナルです。
- ローンチは多いが卒業や稼働が少ないウォレットは、停滞したトークンの履歴を持ちます。購入前に検討する価値があります。
- 評判は 1 つの入力であり、保証ではありません。常にトークン自身の流動性、ホルダー、[取引ガイド](/ja/protocol/trading-guide) の安全上の注記と組み合わせてください。
