# アンチスナイプと公平なローンチの保護

仮想通貨取引における最大のフラストレーションの一つは、プールの流動性をミリ秒単位で買い占める自動スナイパーボットに早期のチャンスを奪われることです。

Goton は、ローンチ最初のブロックの間、組み込みのハードコードされたスマートコントラクトのルールを適用し、一般のコミュニティメンバーが公平に参加できるようにしています。

---

## 仕組み

Goton は、ボンディングカーブのアーキテクチャに**動的に減衰するスナイパー手数料**を採用しています。

- ローンチの正確な瞬間（$t=0$）、即時執行を試みる捕食的なボットには自動で 99% の税が適用されます。
- 手数料はその後 3 秒かけて急速に減衰します（$t=1 \to 25\%$、$t=2 \to 3\%$、$t \ge 3 \to 0\%$）。
- 数秒以内に、人間のトレーダー向けに通常の無税取引がスムーズに再開します。

---

## 透明性と安全性の保証

- **ホワイトリストやゲートキーパーなし**: 公平なローンチのウィンドウが開けば、Web3 ウォレットを持つ誰もが参加できます。
- **管理者スイッチなし**: アンチスナイプの制限は数学的にコントラクトへハードコードされ、人間の介入なしに期限切れになります。
- **売却は常に可能**: ユーザーが購入したトークンに、人為的なロックアップや出金のクールダウンはありません。
