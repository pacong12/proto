# PnL カードと共有

すべてのポジションには共有できる **PnL カード** — トークンでの損益の画像 — があり、投稿、コピー、リンク共有ができます。取引の勝ち（または学び）を見せる最速の方法です。

---

## カードを開く

プロフィールの **Portfolio** タブ、またはトークンの trade view で、ポジションの **Share PnL** アクションを使います。カードが開き、次が表示されます。

- **損益**（USD。例: `+$35.23K`）。測定できる投資がある場合はリターンの**パーセント**付き。
- ポジションの**トークン**。
- Goton のブランド表示。共有時にカードが単独で成立します。

同じカードは専用の共有ページ `goton.fun/pnl/<wallet>/<token>` にもあり、送った相手はブラウザで開けます。

---

## 共有アクション

カードのモーダルは 4 つの共有方法を提供します。

| アクション     | 動作                                                                |
| :------------- | :------------------------------------------------------------------ |
| **Post on X**  | 損益、パーセント、トークン、カードへのリンクを事前入力して X を開く |
| **Copy image** | カードの PNG をクリップボードにコピーし、どこにでも貼り付け可能     |
| **Download**   | カードの PNG をデバイスに保存                                       |
| **Copy link**  | `/pnl/…` ページのリンクをコピー                                     |

カードが生成する各リンク — 投稿したツイートとコピーしたリンク — には、あなたの**リファラルコード**（`?ref=`）が付くため、勝ちを共有することがそのままネットワークの拡大になります。[友達を招待・リファラル](/ja/protocol/referrals) を参照してください。

---

## 注記

- カードは**インデックス済みのオンチェーン取引**からレンダリングされるため、実際の活動を反映します。ポジションをでっち上げることはできません。
- カードのリンクは公開です。開いた人は、そのウォレットとトークンのポジションの損益を見られます。オンチェーン履歴がすでに示している以上のものは公開されません。
- 損益とパーセントはポジションのコストベースを使います。測定可能な投資がないポジションは、パーセントなしで USD 金額を表示します。
