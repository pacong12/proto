# Reputação do Criador

Todo perfil mostra o **histórico de lançamentos** do criador — um resumo rápido, derivado on-chain, do que ele já lançou. Ajuda traders a julgar um token novo pelo histórico da carteira por trás dele.

---

## O que Mostra

O cartão de reputação no perfil de um criador resume cada token que aquela carteira lançou:

| Métrica              | Significado                                                                  |
| :------------------- | :--------------------------------------------------------------------------- |
| **Launches**         | Quantos tokens a carteira criou                                              |
| **Graduated**        | Quantos deles completaram a bonding curve e migraram para um pool Uniswap v4 |
| **Active**           | Quantos ainda estão ativos e sendo negociados                                |
| **Graduation rate**  | Graduated ÷ launches, em porcentagem                                         |
| **Total market cap** | O market cap USD combinado dos tokens do criador                             |
| **Top token**        | O maior token do criador por market cap, com nome, símbolo e market cap      |

---

## Como é Calculado

- Os números são construídos a partir de **dados on-chain** — os tokens que a carteira implantou e seu estado de mercado atual — não de algo que o criador digite.
- **Nada aqui é autodeclarado.** Um criador não pode editar esses números; eles refletem os lançamentos vinculados ao endereço.
- Construindo algo? Os mesmos números estão disponíveis pela [API Pública](/integration/api).

---

## Como Ler como Trader

- Uma **taxa de graduação** alta em vários lançamentos é um sinal mais forte do que um único token graduado.
- Uma carteira com muitos lançamentos mas poucos graduados ou ativos tem um histórico de tokens que estagnaram — vale pesar antes de comprar.
- A reputação é uma entrada, não uma garantia. Combine-a sempre com a liquidez, os holders e as notas de segurança do próprio token no [Guia de Trading](/pt/protocol/trading-guide).
