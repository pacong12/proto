# Tableau de Bord du Portefeuille

Votre profil a un onglet **Portfolio** qui résume l'état de votre trading — profits réalisés et non réalisés, un taux de réussite, et chaque token que vous détenez actuellement — le tout calculé à partir de vos transactions on-chain.

---

## Le Résumé

En haut de l'onglet Portfolio :

| Métrique       | Signification                                                                  |
| :------------- | :----------------------------------------------------------------------------- |
| **Total PnL**  | Profit/perte réalisé + non réalisé sur toutes vos positions, en USD            |
| **Realized**   | Profit/perte que vous avez déjà verrouillé en vendant                          |
| **Unrealized** | Profit/perte sur papier sur les tokens que vous détenez encore, au prix actuel |
| **Win rate**   | La part de vos positions clôturées terminées en profit                         |

Les gains apparaissent en vert, les pertes en rouge, pour lire l'état de votre portefeuille d'un coup d'œil.

---

## Détentions

Sous le résumé, un tableau de **positions ouvertes** liste chaque token que vous détenez actuellement :

- **Actif** — le token.
- **Solde** — combien vous détenez.
- **Prix** — le prix USD actuel du token.
- **Valeur** — la valeur USD actuelle de votre détention.
- **Actions** — allez à la page **trade** du token, ou ouvrez une **carte PnL** pour partager votre position (voir [Inviter des Amis et Parrainage](/fr/protocol/referrals) sur la manière dont les liens partagés portent votre code d'invitation).

Une liste séparée affiche vos **positions clôturées** — les tokens que vous avez entièrement vendus — avec le résultat de chacune.

Si vous ne détenez encore rien, l'onglet vous dirige vers l'exploration et le trading de tokens.

---

## Notes

- Tout est dérivé de vos **transactions on-chain indexées**, pas d'un registre manuel — connectez votre portefeuille et votre historique se remplit automatiquement.
- La liste d'activité est une page de vos transactions les plus récentes, donc une page pleine ne représente pas votre total à vie.
- Vous seul voyez les raccourcis de partage et de trading sur votre propre profil ; les visiteurs voient le même résumé de performance et de détentions pour tout portefeuille qu'ils ouvrent.
