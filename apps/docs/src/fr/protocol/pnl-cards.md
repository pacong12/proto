# Cartes PnL et Partage

Chaque position a une **carte PnL** partageable — une image de vos gains et pertes sur un token que vous pouvez publier, copier ou lier. C'est le moyen le plus rapide de montrer une victoire (ou une leçon) d'une transaction.

---

## Ouvrir une Carte

Depuis l'onglet **Portfolio** de votre profil, ou depuis la trade view d'un token, utilisez l'action **Share PnL** sur une position. Une carte s'ouvre affichant :

- Vos **gains et pertes** en USD (ex. `+$35.23K`), avec le **pourcentage** de rendement lorsqu'il y a un investissement à mesurer.
- Le **token** de la position.
- La marque Goton, pour que la carte tienne seule une fois partagée.

La même carte vit aussi sur sa propre page partageable, `goton.fun/pnl/<wallet>/<token>`, afin que toute personne à qui vous l'envoyez puisse l'ouvrir dans un navigateur.

---

## Actions de Partage

La modale de la carte offre quatre façons de partager :

| Action         | Ce qu'elle fait                                                                       |
| :------------- | :------------------------------------------------------------------------------------ |
| **Post on X**  | Ouvre X avec le PnL, le pourcentage, le token et un lien vers votre carte pré-remplis |
| **Copy image** | Copie le PNG de la carte dans votre presse-papiers pour le coller partout             |
| **Download**   | Enregistre le PNG de la carte sur votre appareil                                      |
| **Copy link**  | Copie le lien de la page `/pnl/…`                                                     |

Chaque lien qu'une carte produit — le tweet publié et le lien copié — porte votre **code de parrainage** (`?ref=`), donc partager une victoire fait aussi croître votre réseau. Voir [Inviter des Amis et Parrainage](/fr/protocol/referrals).

---

## Notes

- La carte est rendue à partir de vos **transactions on-chain indexées**, elle reflète donc une activité réelle — vous ne pouvez pas inventer une position.
- Le lien d'une carte est public : quiconque l'ouvre voit le PnL de cette position pour ce portefeuille et ce token. Il n'expose rien au-delà de ce que l'historique on-chain montre déjà.
- Le PnL et le pourcentage utilisent la base de coût de la position ; une position sans investissement mesurable affiche le montant USD sans pourcentage.
