# 隐私政策

<StatusBadge variant="graduated">最近更新：2026 年 10 月</StatusBadge>

<Card>
Goton Labs 与 Goton 协议在所支持的网络上运营非托管代币发行及去中心化交易前端。我们坚定遵循数据最小化原则，保护用户主权与加密隐私。
</Card>

## 1. 我们绝不收集的信息

因为 Goton 采用纯非托管模式：

- **无私钥收集**：我们绝不生成、读取、传输或存储您的私钥或助记词。
- **无托管账户**：无需注册邮箱，无中心化用户密码，也不托管任何资金。
- **不出售数据**：我们绝不出售用户数据或链上财务活动档案。

## 2. 链上公开处理的信息

当您与智能合约交互时：

- **公开钱包地址**：您的 EVM 地址直接与工厂合约和流动性池交互。
- **公开交易记录**：代币发射、流动性锁定、提款及兑换均透明广播至公共账本。
- **公开 RPC 查询**：标准 JSON-RPC 广播请求直接由对应的公共区块链节点处理。

## 3. 本地存储的使用范围

前端仅在您的浏览器 `localStorage` 中记录必要的偏好配置：

- 钱包连接就绪状态与上次使用的插件标识。
- 深色 / 浅色主题显示偏好。
- 条款协议签署记录。

## 3a. 链下数据、统计分析与您的权利

- **社交功能**：您提交的评论、点赞、转发、情绪投票和创作者资料由 Goton API 与您的钱包地址一同存储并公开展示。
- **服务器日志**：API 出于安全和限流目的保存请求日志，客户端 IP 地址仅以单向哈希形式记录。
- **统计分析**：仅在您接受统计分析 Cookie 后，网页应用才会加载 Google Analytics（`gtag.js`），它会设置 Cookie 并向 Google 发送页面访问和设备数据。您可随时通过应用页脚的 **Cookie 设置** 撤回同意（参见 [Cookie 政策](/zh/cookie-policy)）。
- **删除权**：您可随时在 **Profile → Edit Profile → 删除我的社交数据** 中删除评论、点赞、转发、情绪投票、关注关系和个人资料（API：`DELETE /api/users/{address}/data`，需由该钱包重新签名确认）。链上记录任何人都无法删除。

## 4. 第三方协议与基础设施

交互可能经过以下去中心化基础设施：

- **Robinhood Chain（L2）与 Arc Network**：区块执行与交易共识。
- **Uniswap v4**：持有锁定流动性并执行兑换的池管理合约。
- **Google Analytics**：网页应用的页面访问统计（参见第 3a 节）。
- **IPFS 网关**：代币图标与自描述元数据的去中心化托管。

## 5. 安全与不变量

所有协议后端服务均执行失败即关闭（fail-closed）的安全策略（`INV-BE-3`），并拒绝直接签名（`INV-BE-1`）。智能合约头寸永久锁定在非托管锁仓合约中（`INV-SC-2`）。
