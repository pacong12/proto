# 常见问题解答 (FAQ)

为您解答关于在 Proto 平台上交易、发行和管理代币的核心疑问。

---

## 平台基础

### 什么是 Proto？

Proto 是一个去中心化、非托管的代币发售与交易平台，原生支持 **Robinhood Chain** (L2) 与 **Arc Network** (Circle Stablecoin L1)。允许任何人发行固定总量代币、查看实时行情并在防撤池机制保护下公平交易。

### 开发者是否可以撤池子 (Rug Pull)？

**绝无可能。** 所有的池子流动性仓位在发射瞬间直接铸造到开源智能合约 `LiquidityLocker.sol` 中并永久锁定。合约中没有解锁机制、没有后门，也没有管理员提款私钥。

### 支持哪些钱包？

Proto 支持所有主流 EVM 兼容 Web3 钱包，包括：

- MetaMask
- Coinbase Wallet
- Rabby Wallet
- Rainbow Wallet
- 任何支持 WalletConnect / Reown 的移动端钱包
- 支持 Google、X、Discord、GitHub 社交一键免插件登录（嵌入式非托管钱包）

## 交易相关

### 为什么我的交易会失败？

通常由以下两种原因造成：

1. **超出滑点上限**：在高波动期间，代币价格波动幅度超过了您设置的滑点比例。可在交易面板设置中适当调高滑点容忍度（如 1% 至 2%）。
2. **底层 Gas 不足**：钱包中需要保留少量原生 Gas 资产（Robinhood 链上的 ETH 或 Arc 链上的 USDC）用以支付链上打包执行费用。

### On Curve 与 Graduated 的区别？

- **On Curve**：代币当前正在联合曲线上交易，随着买入代币增加价格稳定上升。
- **Graduated**：代币在曲线上达成募资门槛（4.2 ETH 或 8,400 USDC），已永久迁移并锁定到 Uniswap 流动性池。

### 出售代币是否有限制？

**没有任何限制。** 任何用户均可随时出售其持有的代币，Proto 绝不存在锁仓期、提现冷却期或针对用户的转账冻结机制。

## 代币发行

### 发行一枚代币需要多少费用？

固定协议发射费用为 Robinhood 链上的 **0.0005 ETH** 或 Arc 链上的 **1 USDC**。该费用覆盖智能合约部署、代币铸造以及初始流动性锁定全流程。

### 代币供应量以后是否能增加？

**绝不增发。** Proto 上的所有代币总供应量均恒定为 **1,000,000,000 枚**（10 亿枚）。智能合约中完全没有增发逻辑。

### 创作者如何获得收益分成？

创作者将自动获得其代币交易中 **1% 手续费的 70%**。您可以随时在 **Profile** 个人中心页面查看并一键提取积累的收益。
