# 创作者声誉

每个个人主页都会展示该创作者的**发行记录** —— 一份基于链上数据的简要总结，说明其发行过什么。它帮助交易者通过背后钱包的历史来判断一个新代币。

---

## 展示内容

创作者主页上的声誉卡片汇总了该钱包发行过的每个代币：

| 指标                 | 含义                                                      |
| :------------------- | :-------------------------------------------------------- |
| **Launches**         | 该钱包创建了多少个代币                                    |
| **Graduated**        | 其中有多少完成了 bonding curve 并迁移到 Uniswap v4 资金池 |
| **Active**           | 有多少仍在活跃交易                                        |
| **Graduation rate**  | Graduated ÷ launches，以百分比表示                        |
| **Total market cap** | 该创作者各代币的合计 USD 市值                             |
| **Top token**        | 该创作者市值最大的代币，含名称、符号与市值                |

---

## 如何计算

- 这些数字由**链上数据**构建 —— 该钱包部署的代币及其当前市场状态 —— 而非创作者自行填写。
- **此处无任何自我申报。** 创作者无法编辑这些数字；它们反映绑定到该地址的发行记录。
- 在开发工具？同样的数字可通过[公开 API](/zh/integration/api) 获取。

---

## 作为交易者如何解读

- 在多次发行中保持较高的**毕业率（graduation rate）**，比单个毕业代币是更强的信号。
- 发行很多但毕业或活跃很少的钱包，有一段代币停滞的历史 —— 买入前值得权衡。
- 声誉是一个参考，而非保证。请始终结合代币自身的流动性、持有者，以及[交易指南](/zh/protocol/trading-guide)中的安全提示。
