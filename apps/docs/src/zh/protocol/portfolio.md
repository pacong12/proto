# 投资组合面板

你的主页有一个**投资组合（Portfolio）**标签页，汇总你的交易表现 —— 已实现与未实现盈亏、胜率，以及你当前持有的每个代币 —— 全部由你的链上交易计算得出。

---

## 概览

投资组合标签页顶部：

| 指标           | 含义                                       |
| :------------- | :----------------------------------------- |
| **Total PnL**  | 各持仓的已实现 + 未实现盈亏合计，以 USD 计 |
| **Realized**   | 你已通过卖出锁定的盈亏                     |
| **Unrealized** | 你仍持有代币按当前价格计的账面盈亏         |
| **Win rate**   | 你已平仓头寸中盈利的比例                   |

盈利显示为绿色，亏损为红色，让你的账面状态一目了然。

---

## 持仓

概览下方，一张**未平仓**表格列出你当前持有的每个代币：

- **资产** —— 代币本身。
- **余额** —— 你持有多少。
- **价格** —— 代币当前 USD 价格。
- **价值** —— 你持仓的当前 USD 价值。
- **操作** —— 跳转到代币的**交易**页，或打开 **PnL 卡片**分享你的持仓（参见[邀请好友与推荐](/zh/protocol/referrals)，了解分享链接如何携带你的邀请码）。

另有一张列表显示你的**已平仓头寸** —— 你已全部卖出的代币 —— 及每笔的结果。

如果你尚未持有任何代币，该标签页会引导你去浏览并交易代币。

---

## 说明

- 一切都由你**已索引的链上交易**得出，而非手动账本 —— 连接钱包后你的历史会自动填充。
- 活动列表是你最近交易的一页，因此满满一页并不代表你的终身总量。
- 只有你能在自己主页上看到分享与交易快捷入口；访客对其打开的任意钱包，看到的是相同的表现概览与持仓。
