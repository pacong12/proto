# 如何发行代币

在 Proto 上创建您自己的代币只需不到两分钟，且不需要任何编程或区块链开发经验。

---

## 详细操作指南

### 1. 连接您的钱包

访问 [proto.family](https://proto.family) 并点击顶部导航栏中的 **Connect Wallet**。确保钱包已切换至 **Robinhood Chain** 或 **Arc Network**。

### 2. 进入创建页面

点击导航中的 **Create** 或直接访问 `/launchpad/create`。

### 3. 选择发售架构

选择最符合您预期的模式：

- **v2 联合曲线模式（推荐）**：始于交互式联合曲线，代币价格随着买入量的增加而平滑上升，在达到募资阈值后自动毕业至 Uniswap。
- **v1 直接池模式**：直接创建完整的 Uniswap V3 流动性池并完成永久锁定。

### 4. 填写代币信息

输入代币的基本要素：

- **代币名称 (Name)**：代币的全名（例如：`Robin Gold`）。
- **代码代码 (Symbol)**：3 至 6 个大写英文字母（例如：`GOLD`）。
- **项目描述 (Description)**：简要介绍代币的愿景、社区目标与设计初心。
- **代币头像 (Logo)**：上传图片文件（PNG、JPG、SVG 或 WebP）。系统会自动完成压缩并安全上传固定至去中心化 IPFS 网络。

### 5. 绑定社交主页（可选）

添加官方社交渠道以供交易者验证：

- 官方网站 URL
- 官方 X (Twitter) 账号
- 社区 Telegram 链接

### 6. 创作者初始买入（可选）

如果您希望在最初始价格买入创作者预购份额，可输入对应的购买金额。

### 7. 确认并部署

点击 **Launch Token** 并在您的钱包中确认签名：

- **发射费用**：固定为 Robinhood 链上的 `0.0005 ETH` 或 Arc 链上的 `1 USDC`，用于智能合约部署与流动性锁定初始化。
- 交易在链上确认后，您的代币即可直接公开交易！

---

## 代币供应机制保障

通过 Proto 部署的所有代币均遵循严格的代码不可变规则：

- **总供应量**：恒定正好 **1,000,000,000 枚**（10 亿枚）。
- **代币精度**：18。
- **无增发接口**：合约中不存在增发新代币的任何函数。
- **无黑名单/无冻结**：代币转账无法被恶意暂停或冻结。
