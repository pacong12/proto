# 如何发行代币

在 Goton 上创建您自己的代币只需不到两分钟，且不需要任何编程或区块链开发经验。

---

## 详细操作指南

### 1. 连接您的钱包

访问 [%APP_HOST%](%APP_URL%) 并点击顶部导航栏中的 **Connect Wallet**。确保钱包已切换至 **Robinhood Chain** 或 **Arc Network**。

### 2. 进入创建页面

点击导航中的 **Create** 或直接访问 `/launchpad/create`。

### 3. 填写代币信息

输入代币的基本要素：

- **代币名称 (Name)**：代币的全名（例如：`Robin Gold`）。
- **代码代码 (Symbol)**：3 至 6 个大写英文字母（例如：`GOLD`）。
- **项目描述 (Description)**：简要介绍代币的愿景、社区目标与设计初心。
- **代币头像 (Logo)**：上传图片文件（PNG、JPG、SVG 或 WebP）。系统会自动完成压缩并安全上传固定至去中心化 IPFS 网络。

### 4. 绑定社交主页（可选）

添加官方社交渠道以供交易者验证：

- 官方网站 URL
- 官方 X (Twitter) 账号
- 社区 Telegram 链接

### 5. 创作者初始买入（可选）

如果您希望在最初始价格买入创作者预购份额，可输入对应的购买金额（Robinhood Chain 使用 ETH，Arc 使用 USDC）。初始买入加上书面描述，也是发行进入 [Memestock](/zh/protocol/social#memestock) 的条件。

### 6. 确认并部署

点击 **Launch Token** 并在您的钱包中确认签名：

- **发射费用**：Robinhood 链上固定为 `0.0005 ETH`，Arc 链上为 `0 USDC`（免发射费，需满足最低 4.50 USDC 预买）。
- 交易在链上确认后，您的代币即可直接公开交易！

---

## 代币供应机制保障

通过 Goton 部署的所有代币均遵循严格的代码不可变规则：

- **总供应量**：恒定正好 **1,000,000,000 枚**（10 亿枚）。
- **代币精度**：18。
- **无增发接口**：合约中不存在增发新代币的任何函数。
- **无黑名单/无冻结**：代币转账无法被恶意暂停或冻结。

---

## 毕业

- **Robinhood Chain**：代币在其联合曲线上交易，直到曲线募集 **4.2 ETH**。随后曲线关闭，其 ETH 和剩余代币转入流动性永久锁定的 Uniswap v4 池。毕业无需许可：Goton 的 keeper 会在约 30 秒内触发，若有人先交易，则由其交易触发。
- **Arc Network**：没有联合曲线。代币从第一个区块起就在锁定的 Uniswap v4 池中交易。

毕业后代币仍在同一页面交易，应用会将交易路由到池子。
