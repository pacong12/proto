# 个人主页与身份

Goton 上的每个钱包都有一个公开主页和内置**化名（pseudonym）**，因此从第一笔交易起你就拥有名字和主页 —— 无需注册。只要连接钱包，你随时可以自定义主页。

---

## 你的化名

钱包一出现，Goton 就会用其地址派生出一个确定性的用户名 —— 一个形容词、一种材质和一个原型，再加上来自地址的简短标签，例如 **AeroBrassGriffin#79c8**。由此衍生出三种形式，均指向同一个钱包：

- **显示名** —— `AeroBrassGriffin#79c8`
- **Handle** —— `@AeroBrassGriffin#79c8`
- **Slug** —— `aerobrassgriffin-79c8`（URL 安全形式）

由于由地址派生，你的化名**永不改变**，并在应用各处保持一致。它也是你的[推荐链接](/zh/protocol/referrals)所使用的。

---

## 主页 URL

主页可通过多个等价路径打开，它们都解析到同一个钱包：

- `/u/<地址>`、`/profile/<地址>`、`/user/<地址>`、`/@<地址>`
- `/<用户名>` —— 即 slug，例如 `/aerobrassgriffin-79c8`

地址形式的 URL 会被改写为简洁的 `/<用户名>` 形式。输入的名称、slug 或 handle 会被解析回其地址，因此分享名称与分享地址同样有效。

---

## 编辑你的主页

在**你自己的**主页上（已连接钱包），**Edit Profile** 让你自定义公开的创作者身份：

| 字段            | 说明                                   |
| :-------------- | :------------------------------------- |
| **封面横幅**    | 从你的设备上传的图片                   |
| **头像**        | 从你的设备上传的头像                   |
| **显示名**      | 最多 32 个字符；公开覆盖化名           |
| **简介**        | 简短描述 —— 策略、你的 alpha，任何内容 |
| **X (Twitter)** | 你的用户名                             |
| **Telegram**    | 你的用户名                             |

上传的图片存储在 IPFS；主页其余内容按你的钱包保存。你也可以**清除**社交数据，以清空自定义字段并回退到化名。

---

## 主页展示内容

每个主页 —— 无论你的还是他人的 —— 都把该钱包的活动集中在一处：

- **[创作者声誉](/zh/protocol/reputation)** —— 他们的发行记录。
- **[投资组合](/zh/protocol/portfolio)** —— 表现与当前持仓。
- **Posts & Calls** —— 他们的[动态](/zh/protocol/social)活动。
- **Created Tokens** —— 该钱包发行的代币。
- **[持有者分红与解锁](/zh/protocol/dividends-and-vesting)** —— 可领取的奖励（自己的主页）。
- **[邀请好友](/zh/protocol/referrals)** —— 他们的邀请链接（自己的主页）。

---

## 说明

- 主页是**公开的**，由链上活动加上你设置的可选字段构建。它不会暴露链与你自身编辑之外的任何信息。
- 不存在账号、邮箱或密码 —— 你的钱包*就是*你的身份。
