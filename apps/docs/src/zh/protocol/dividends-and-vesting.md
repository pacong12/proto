# 持有者分红与线性解锁

你主页上的 **Dividends（分红）**标签页用于领取两类链上奖励：你所持代币的**持有者手续费分成分红**，以及随时间解锁的**线性释放（vesting）代币**。两者都直接领取到你的钱包。

---

## 持有者分红

部分代币在发行时开启了 **Holder Fee Sharing（持有者手续费分成）**。对这些代币，一部分交易手续费会**按比例累积给所有持有者** —— 而不仅是创作者。

在 Dividends 标签页你会看到：

- **Total claimable（可领取合计）** —— 你累积的奖励，按币种列出（Robinhood 上为 ETH / WETH，Arc 上为 USDC）。
- **按代币条目** —— 你持有的每个参与手续费分成的代币，以及等待你领取的金额。
- **Claim all（全部领取）** —— 一次领取所有代币的分红，或从某行单独领取一个代币。

只要代币在交易，奖励就会持续累积；领取会把已累积的部分扫入你的钱包。只有当创作者开启了 Holder Fee Sharing，代币才会出现在此 —— 参见[创作者分成与奖励](/zh/protocol/fees-and-burns)了解手续费分配如何配置。

---

## 线性解锁（Vesting）

当某代币授予你随时间解锁的额度（例如创作者或贡献者额度）时，其**解锁时间表**会显示在同一标签页，按代币列出：

| 字段                | 含义                       |
| :------------------ | :------------------------- |
| **Total（仍锁定）** | 尚未解锁的代币             |
| **Claimed**         | 你已释放到钱包的代币       |
| **Claimable**       | 你现在即可释放的已解锁代币 |
| **Cliff ends**      | 在此日期之前不会有任何解锁 |
| **Fully unlocked**  | 整个额度完成解锁的日期     |

时间表包含一个 **cliff（悬崖期）**（在该日期前不释放），之后逐步解锁直至完全释放。解锁头寸上有两个操作：

- **Claim tokens** —— 将当前可领取（已解锁）的代币释放到你的钱包。
- **Claim dividends** —— 领取该解锁头寸所赚取的持有者手续费分成分红。

---

## 说明

- 一切均在**链上**。领取是一笔钱包交易；解锁与手续费分成逻辑存在于代币合约中，没有任何管理员能挪用你的奖励。
- 该标签页仅在**你自己的**主页上显示你的可领取金额与解锁（请连接钱包）。金额会随代币交易以及解锁越过 cliff 而更新。
