# 什么是 Proto？

**Proto** 是部署在 **Robinhood Chain (Chain ID: 4663)** 与 **Arc Network (Chain ID: 5042)** 上的社区优先、非托管加密代币发射平台与交易协议。

它为任何人提供了一个安全、透明、公平的环境，无需复杂的金融门槛、隐秘预售或突然撤出流动性（_Rug pull_）的风险，即可发行、交易和发现数字资产。

---

## 为什么选择 Proto？

在传统的代币发射平台上，普通用户常面临多种系统性风险：

1. **撤池子与跑路风险 (Rug Pulls)**：发行者创建代币，等散户入场后，立即撤出池中所有底层资产。
   - **Proto 的解决方案**：每个池子的流动性仓位在发射瞬间直接铸造并永久锁定在开源智能合约 (`LiquidityLocker.sol`) 中。没有任何个人、创作者或平台管理员拥有解锁或提取储备金的权限。
2. **狙击机器人与夹子交易**：高速自动化机器人常在第一秒掠夺绝大多数代币并在随后砸盘。
   - **Proto 的解决方案**：内置的硬编码反抢跑机制在发射初始窗口期限制单笔购买上限与单钱包持仓比例，保障社区用户的公平参与。
3. **隐藏团队预留份额**：许多项目隐秘向内部团队分配大量代币。
   - **Proto 的解决方案**：严格固定总供应量为 **1,000,000,000 枚代币**（10 亿枚），全部透明铸造在链上，且不存在任何增发接口。

## 两种简洁的发售模式

根据您的项目目标，Proto 提供两种发售模式供您选择：

| 模式                            | 工作原理                                                                                                                                                     | 适用场景                                                    |
| :------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- |
| **v1 直接池 (Direct Pool)**     | 代币直接发射到活跃的 Uniswap V3 流动性池中，100% 的非创作者供应量自第一天起永久锁定。                                                                        | 希望从第一个区块开始就具备完整 DEX 流动性深度的项目。       |
| **v2 联合曲线 (Bonding Curve)** | 始于动态价格曲线。8 亿枚代币随着买家入场逐步售出。当达到毕业目标（Robinhood 链上 4.2 ETH 或 Arc 链上 8,400 USDC）后，市场自动毕业并迁移到完整 DEX 流动性池。 | 社区代币、Meme 币以及希望进行渐进式价格发现的社交实验项目。 |

## 准备开始

使用 Proto 仅需三步：

1. 准备一个与 EVM 兼容的 Web3 钱包（如 MetaMask、Coinbase Wallet、Rabby 或 Rainbow）。
2. 在钱包中添加 Robinhood Chain 或 Arc Network 网络。
3. 拥有少量底层 Gas 资产（Robinhood 链上的 ETH 或 Arc 链上的 USDC）以支付网络交易费。

接下来请查阅 [如何发行代币](/zh/protocol/launches) 或阅读 [交易与兑换指南](/zh/protocol/trading-guide)。
