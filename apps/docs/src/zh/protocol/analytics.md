# 协议分析

**Analytics（分析）**页面提供 Goton 全网活动的实时视图 —— 交易量多少、发行了多少代币、协议产生了多少手续费 —— 针对你当前所在的网络。

---

## 主图表

一张交互式图表以分桶方式绘制**过去 24 小时**内的某一指标。切换指标：

| 指标         | 绘制内容             |
| :----------- | :------------------- |
| **Volume**   | 交易量随时间变化     |
| **Launches** | 代币发行数随时间变化 |
| **Fees**     | 协议手续费随时间产生 |

可在**平滑面积图**与**柱状图**之间切换。所有内容都限定于**当前网络**（Robinhood 或 Arc）—— 从头部切换网络即可查看另一条链的数据。

---

## 关键统计

图表下方，汇总卡片展示该网络的总量，包括：

- **总交易量** —— 网络的整体交易量。
- **发行代币总数** —— 已创建多少代币。
- **税费 / 手续费估算** —— 对所产生手续费的估算。
- **Buyback（回购）** —— 协议回购活动（如有）。

一张**热门代币**列表按市值排序，让你能从宏观视图直接跳到某个代币的交易页。

---

## 说明

- 数据由**链上数据**构建，并随新区块的处理而更新。想在自己的工具中获取相同数字？它们都在[公开 API](/zh/integration/api) 中。
- 分析按**网络**划分：页面始终反映头部所示的链，并在其范围说明中注明。
- 数字源自索引器，随新区块处理而更新；24 小时窗口为滚动视图，而非自然日。
