# 防抢跑与公平发售保障

在加密市场中，许多散户常常苦恼于自动化狙击机器人在几毫秒内将池子初始筹码扫光并砸盘。

Proto 在代币发售的最前序区块中执行硬编码的智能合约规则，确保社区普通用户享有平等的参与机会。

---

## 运作机制

### 对于 v1 直接池模式 (Uniswap V3)

在池子初始化的前 2 个区块内：

1. **区块 0（发射区块）**：
   - 仅允许创作者的可选初始买入交易与合约创建在同区块内打包。
   - 外部机器人试图在此区块抢跑排队的交易将全部被系统驳回。
2. **区块 1 与区块 2**：
   - **单笔交易限额**：单笔购买数量不得超过**总供应量的 5.5%**（55,000,000 枚）。
   - **单个钱包持仓上限**：单个地址买入后的总持仓不得超过**总供应量的 5.0%**（50,000,000 枚）。
3. **区块 3 及以后**：
   - 所有的限额规则在智能合约字节码层面自动失效。市场进入完全开放、免限制的标准状态。
   - **出售从不受限**：任何买入者均可随时向池子出售代币，即使在限制窗口期内也同样自由。

---

### 对于 v2 联合曲线模式

在联合曲线上，Proto 采用**动态平滑递减的防夹狙击费率**：

- 在发射瞬间的第一秒 ($t=0$)，任何企图瞬时抢跑的恶意机器人将面临 99% 的惩罚性费率。
- 随后该费率在 3 秒内平滑递减归零（$t=1 \to 25\%$, $t=2 \to 3\%$, $t \ge 3 \to 0\%$）。
- 几秒之内，正常社区交易者即可享受零附加税的常规交易。

---

## 透明度与安全承诺

- **无白名单无门槛**：只要公平发射窗口开启，拥有 Web3 钱包的任何人均可自由参与。
- **无管理员后门开关**：反抢跑规则以数学逻辑硬编码在合约内部，到期自动失效，无需任何人工权限介入。
