# PnL 卡片与分享

每个持仓都有一张可分享的 **PnL 卡片** —— 一张展示你在某代币上盈亏的图片，可用于发帖、复制或链接分享。这是展示一笔交易胜绩（或教训）的最快方式。

---

## 打开卡片

在你主页的 **Portfolio** 标签页，或在某代币的交易页，对某个持仓使用 **Share PnL** 操作。会打开一张卡片，显示：

- 你的**盈亏**（USD，例如 `+$35.23K`），在有可衡量投入时附带**百分比**回报。
- 持仓所在的**代币**。
- Goton 品牌标识，使卡片在分享时可独立成立。

同一张卡片也拥有自己的可分享页面 `goton.fun/pnl/<wallet>/<token>`，因此你发送给的任何人都能在浏览器中打开。

---

## 分享操作

卡片弹窗提供四种分享方式：

| 操作           | 作用                                           |
| :------------- | :--------------------------------------------- |
| **Post on X**  | 打开 X，并预填盈亏、百分比、代币及你卡片的链接 |
| **Copy image** | 将卡片 PNG 复制到剪贴板，可粘贴到任意位置      |
| **Download**   | 将卡片 PNG 保存到你的设备                      |
| **Copy link**  | 复制 `/pnl/…` 页面链接                         |

卡片生成的每个链接 —— 发布的推文和复制的链接 —— 都携带你的**推荐码**（`?ref=`），因此分享胜绩也会扩大你的网络。参见[邀请好友与推荐](/zh/protocol/referrals)。

---

## 说明

- 卡片由你**已索引的链上交易**渲染，因此反映真实活动 —— 你无法伪造持仓。
- 卡片链接是公开的：任何打开它的人都能看到该钱包与代币的持仓盈亏。它不会暴露链上历史之外的任何信息。
- 盈亏与百分比使用持仓的成本基准；没有可衡量投入的持仓只显示 USD 金额而不含百分比。
