# Cookie 与本地存储政策

<Badge variant="graduated">最近更新：2026 年 9 月</Badge>

<Card>
Proto 建立在去中心化隐私的核心理念之上。我们不使用追踪 Cookie、商业广告分析器或任何第三方跨站画像脚本。
</Card>

## 1. 我们使用的技术说明

与传统互联网网站不同，Proto 不使用持久化 HTTP Cookie 来跨站追踪您的浏览行为。我们仅使用浏览器原生的客户端存储（`localStorage` 和 `sessionStorage`）来保存必要的前端界面状态。

## 2. 本地存储的数据项

| 存储标识键                         | 用途说明                                        | 留存周期                 |
| :--------------------------------- | :---------------------------------------------- | :----------------------- |
| `proto_privacy_policy_accepted_v1` | 记录您已阅读并同意服务条款与隐私政策            | 持久保存（直至手动清除） |
| `theme`                            | 记录您的深色模式 (Dark) 或浅色模式 (Light) 偏好 | 持久保存（直至手动清除） |
| `wagmi.wallet` / `wc@2:client`     | 记录已连接钱包的会话句柄，避免刷新页面重复授权  | 会话或持久存储           |

## 3. 绝无第三方追踪

- **零商业追踪插件**：绝不植入 Google Analytics、Facebook Pixel 等行为跟踪代码。
- **零设备指纹**：绝不探测或采集硬件信息、Canvas 指纹或真实 IP 定位。
- **零数据货币化**：绝不向任何数据中介转让或出售用户偏好。
