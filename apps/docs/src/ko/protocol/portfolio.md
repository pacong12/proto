# 포트폴리오 대시보드

프로필에는 **Portfolio** 탭이 있어 거래 현황 — 실현·미실현 손익, 승률, 현재 보유 중인 각 토큰 — 을 요약합니다. 모두 당신의 온체인 거래에서 계산됩니다.

---

## 요약

Portfolio 탭 상단:

| 지표           | 의미                                           |
| :------------- | :--------------------------------------------- |
| **Total PnL**  | 모든 포지션의 실현 + 미실현 손익 합계(USD)     |
| **Realized**   | 판매로 이미 확정한 손익                        |
| **Unrealized** | 아직 보유 중인 토큰의 현재 가격 기준 평가 손익 |
| **Win rate**   | 종료된 포지션 중 수익으로 끝난 비율            |

이익은 녹색, 손실은 빨간색으로 표시되어 계정 상태를 한눈에 읽을 수 있습니다.

---

## 보유

요약 아래에 **오픈 포지션** 테이블이 현재 보유 중인 각 토큰을 나열합니다.

- **자산** — 토큰.
- **잔액** — 보유량.
- **가격** — 토큰의 현재 USD 가격.
- **가치** — 보유의 현재 USD 가치.
- **동작** — 토큰의 **trade** 페이지로 이동하거나, **PnL 카드**를 열어 포지션을 공유합니다(공유 링크가 초대 코드를 어떻게 담는지는 [친구 초대 및 추천](/ko/protocol/referrals) 참조).

별도의 목록은 **종료된 포지션** — 완전히 판매한 토큰 — 을 각각의 결과와 함께 표시합니다.

아직 아무것도 보유하지 않았다면, 탭은 토큰 탐색과 거래로 안내합니다.

---

## 참고

- 모든 것은 **인덱싱된 온체인 거래**에서 도출되며 수동 장부가 아닙니다. 지갑을 연결하면 이력이 자동으로 채워집니다.
- 활동 목록은 가장 최근 거래의 한 페이지이므로, 가득 찬 페이지가 평생 총량을 나타내지는 않습니다.
- 자신의 프로필에서 공유·거래 단축키는 당신만 봅니다. 방문자는 자신이 연 모든 지갑에 대해 동일한 성과 요약과 보유를 봅니다.
