# 크리에이터 평판

모든 프로필은 크리에이터의 **론칭 이력** — 무엇을 출시했는지에 대한, 온체인에서 도출된 빠른 요약 — 을 표시합니다. 트레이더가 배후 지갑의 이력으로 새 토큰을 판단하는 데 도움이 됩니다.

---

## 표시 내용

크리에이터 프로필의 평판 카드는 그 지갑이 론칭한 각 토큰을 요약합니다.

| 지표                 | 의미                                                            |
| :------------------- | :-------------------------------------------------------------- |
| **Launches**         | 지갑이 생성한 토큰 수                                           |
| **Graduated**        | 그중 본딩 커브를 완료하고 Uniswap v4 풀로 이동한 수             |
| **Active**           | 여전히 가동 중이며 거래되는 수                                  |
| **Graduation rate**  | Graduated ÷ Launches(백분율)                                    |
| **Total market cap** | 크리에이터 토큰의 합산 USD 시가총액                             |
| **Top token**        | 시가총액이 가장 큰 크리에이터의 토큰(이름, 심볼, 시가총액 포함) |

---

## 계산 방식

- 수치는 **온체인 데이터**(지갑이 배포한 토큰과 현재 시장 상태)로 구성되며, 크리에이터가 입력하는 것이 아닙니다.
- **여기에 자가 보고는 없습니다.** 크리에이터는 이 수치를 편집할 수 없으며, 주소에 연결된 론칭을 반영합니다.
- 무언가 만들고 있나요? 같은 수치는 [공개 API](/integration/api)를 통해 이용할 수 있습니다.

---

## 트레이더로서 읽는 법

- 여러 론칭에 걸친 높은 **졸업률**은 단일 졸업 토큰보다 강한 신호입니다.
- 론칭은 많지만 졸업이나 가동이 적은 지갑은 정체된 토큰의 이력을 가집니다. 구매 전에 따져볼 가치가 있습니다.
- 평판은 하나의 입력이지 보장이 아닙니다. 항상 토큰 자체의 유동성, 홀더, [거래 가이드](/ko/protocol/trading-guide)의 안전 참고 사항과 함께 고려하세요.
