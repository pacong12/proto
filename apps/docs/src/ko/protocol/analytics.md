# 프로토콜 분석

**Analytics** 페이지는 Goton의 활동 — 얼마나 거래되는지, 토큰이 몇 개 론칭되는지, 프로토콜이 생성하는 수수료 — 을 현재 있는 네트워크에 대해 네트워크 전체의 실시간 뷰로 제공합니다.

---

## 메인 차트

하나의 인터랙티브 차트가 **최근 24시간**의 한 지표를 구간별로 그립니다. 지표를 전환하세요.

| 지표         | 그리는 내용                        |
| :----------- | :--------------------------------- |
| **Volume**   | 시간에 따른 거래량                 |
| **Launches** | 시간에 따른 론칭된 토큰            |
| **Fees**     | 시간에 따른 생성된 프로토콜 수수료 |

**부드러운 영역** 뷰와 **막대** 뷰를 전환할 수 있습니다. 모든 것은 **활성 네트워크**(Robinhood 또는 Arc)로 한정됩니다. 다른 체인의 수치를 보려면 헤더에서 네트워크를 전환하세요.

---

## 주요 통계

차트 아래에 요약 카드가 네트워크의 합계를 표시합니다. 포함 내용:

- **총 거래량** — 네트워크의 전체 거래량.
- **총 론칭 토큰 수** — 생성된 토큰 수.
- **세금 / 수수료 추정** — 생성된 수수료의 추정치.
- **Buyback** — 프로토콜의 바이백 활동(있을 경우).

**상위 토큰** 목록은 토큰을 시가총액순으로 정렬하여, 거시적 뷰에서 특정 토큰의 trade 페이지로 바로 이동할 수 있게 합니다.

## 참고

- 수치는 **온체인 데이터**로 구성되며 새 블록이 처리됨에 따라 갱신됩니다. 같은 수치를 자신의 도구에 쓰고 싶나요? [공개 API](/integration/api)에 있습니다.
- 분석은 **네트워크별**입니다. 페이지는 항상 헤더에 표시된 체인을 반영하며, 범위 참고 사항에서 이를 밝힙니다.
- 수치는 인덱서에서 도출되며 새 블록이 처리됨에 따라 갱신됩니다. 24시간 창은 달력상의 하루가 아니라 이동하는 뷰입니다.
