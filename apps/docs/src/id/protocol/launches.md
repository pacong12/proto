# Cara Meluncurkan Token

Membuat token sendiri di Proto dapat diselesaikan dalam waktu kurang dari dua menit tanpa memerlukan keahlian coding atau pemrograman blockchain.

---

## Panduan Langkah Demi Langkah

### 1. Hubungkan Dompet Anda

Kunjungi [proto.family](https://proto.family) dan klik **Connect Wallet** di bilah navigasi atas. Pastikan dompet terhubung ke **Robinhood Chain** atau **Arc Network**.

### 2. Buka Halaman Create

Klik menu **Create** atau navigasikan langsung ke `/launchpad/create`.

### 3. Tentukan Model Peluncuran

Pilih antara:

- **v2 Bonding Curve (Direkomendasikan)**: Dimulai di kurva harga interaktif di mana harga naik seiring volume pembelian, lalu otomatis lulus ke Uniswap setelah target tercapai.
- **v1 Direct Pool**: Langsung mencetak pool Uniswap V3 dengan likuiditas yang terkunci permanen.

### 4. Lengkapi Informasi Token

Masukkan data esensial untuk token Anda:

- **Nama Token**: Nama lengkap token (contoh: `Robin Gold`).
- **Simbol Ticker**: 3 sampai 6 huruf kapital (contoh: `GOLD`).
- **Deskripsi**: Penjelasan singkat tentang visi, komunitas, atau tujuan token Anda.
- **Logo Token**: Unggah file gambar (PNG, JPG, SVG, atau WebP). Sistem secara otomatis mengompres gambar dan menyematkannya ke IPFS.

### 5. Tautan Media Sosial (Opsional)

Sertakan tautan resmi agar para trader dapat memverifikasi komunitas Anda:

- URL Situs Web
- Akun resmi X (Twitter)
- Tautan grup Telegram komunitas

### 6. Pembelian Awal / Developer Buy (Opsional)

Jika Anda ingin memiliki alokasi awal sebagai kreator pada harga terendah peluncuran, masukkan nominal pembelian yang diinginkan.

### 7. Konfirmasi & Peluncuran

Klik **Launch Token** dan konfirmasikan transaksi melalui dompet Web3 Anda:

- **Biaya Peluncuran**: Tetap sebesar `0.0005 ETH` di Robinhood Chain atau `1 USDC` di Arc Network untuk penyebaran kontrak dan penguncian likuiditas.
- Setelah transaksi terkonfirmasi, token Anda langsung aktif dan dapat diperdagangkan seketika!

---

## Ketentuan Pasokan Token

Setiap token yang dibuat melalui Proto memiliki pasokan yang mutlak dan tidak dapat diubah:

- **Total Pasokan**: Tepat **1.000.000.000 token** (1 Miliar).
- **Desimal**: 18.
- **Tanpa Pencetakan Tambahan**: Tidak tersedia fungsi pencetakan token baru setelah peluncuran.
- **Tanpa Pembekuan**: Token tidak dapat dibekukan atau dimasukkan ke daftar hitam.
