# Konfigurasi Jaringan & Pengaturan Dompet

Proto beroperasi sebagai launchpad multi-chain yang mendukung **Robinhood Chain Layer 2** dan **Arc Network (Circle Stablecoin L1)**, menghadirkan kecepatan transaksi tinggi, latensi rendah, dan biaya eksekusi yang stabil.

Untuk berinteraksi dengan Proto, tambahkan jaringan yang diinginkan ke dompet Web3 Anda.

---

## 1. Robinhood Chain (Mainnet)

| Parameter              | Nilai                                     |
| :--------------------- | :---------------------------------------- |
| **Nama Jaringan**      | Robinhood Chain                           |
| **RPC URL**            | `https://rpc.mainnet.chain.robinhood.com` |
| **Chain ID**           | `4663`                                    |
| **Simbol Mata Uang**   | `ETH` (18 desimal)                        |
| **URL Block Explorer** | `https://robinhoodchain.blockscout.com`   |

---

## Koneksi Satu Klik & Pergantian Jaringan

Saat membuka [proto.family](https://proto.family), sistem secara otomatis mendeteksi jaringan dompet Anda dan menyediakan opsi perpindahan instan antara **Robinhood Chain** dan **Arc Network** melalui menu pilihan jaringan di bilah navigasi atas.
