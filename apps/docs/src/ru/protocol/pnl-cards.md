# PnL-карточки и шеринг

У каждой позиции есть карточка **PnL**, которой можно поделиться — изображение вашей прибыли и убытка по токену, которое можно опубликовать, скопировать или дать ссылкой. Это самый быстрый способ показать победу (или урок) из сделки.

---

## Открытие карточки

На вкладке **Portfolio** в профиле или в trade view токена используйте действие **Share PnL** для позиции. Откроется карточка, показывающая:

- Ваши **прибыль и убыток** в USD (например, `+$35.23K`), с **процентом** доходности, когда есть измеримая инвестиция.
- **Токен** позиции.
- Брендинг Goton, чтобы карточка была самодостаточной при шеринге.

Та же карточка живёт и на собственной странице для шеринга, `goton.fun/pnl/<wallet>/<token>`, так что любой, кому вы её отправите, может открыть её в браузере.

---

## Действия шеринга

Модальное окно карточки предлагает четыре способа поделиться:

| Действие       | Что делает                                                                            |
| :------------- | :------------------------------------------------------------------------------------ |
| **Post on X**  | Открывает X с заранее заполненными PnL, процентом, токеном и ссылкой на вашу карточку |
| **Copy image** | Копирует PNG карточки в буфер обмена для вставки где угодно                           |
| **Download**   | Сохраняет PNG карточки на устройство                                                  |
| **Copy link**  | Копирует ссылку страницы `/pnl/…`                                                     |

Каждая ссылка, которую создаёт карточка — опубликованный твит и скопированная ссылка — несёт ваш **реферальный код** (`?ref=`), поэтому делиться победой — значит расширять свою сеть. См. [Приглашайте друзей и рефералы](/ru/protocol/referrals).

---

## Примечания

- Карточка рендерится из ваших **индексированных ончейн-сделок**, поэтому отражает реальную активность — нельзя выдумать позицию.
- Ссылка карточки публична: любой, кто её откроет, видит PnL этой позиции для этого кошелька и токена. Она не раскрывает ничего сверх того, что уже показывает ончейн-история.
- PnL и процент используют себестоимость позиции; позиция без измеримой инвестиции показывает сумму в USD без процента.
