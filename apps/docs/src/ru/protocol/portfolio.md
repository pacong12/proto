# Панель портфеля

В профиле есть вкладка **Portfolio**, которая обобщает, как идёт ваша торговля — реализованная и нереализованная прибыль, винрейт и каждый токен, который вы сейчас держите — всё рассчитано из ваших ончейн-сделок.

---

## Сводка

В верхней части вкладки Portfolio:

| Метрика        | Значение                                                                    |
| :------------- | :-------------------------------------------------------------------------- |
| **Total PnL**  | Реализованная + нереализованная прибыль/убыток по всем позициям, в USD      |
| **Realized**   | Прибыль/убыток, который вы уже зафиксировали продажей                       |
| **Unrealized** | Бумажная прибыль/убыток по токенам, которые вы ещё держите, по текущей цене |
| **Win rate**   | Доля ваших закрытых позиций, завершившихся в прибыли                        |

Прибыль показывается зелёным, убытки — красным, чтобы состояние вашего счёта читалось с первого взгляда.

---

## Владения

Под сводкой таблица **открытых позиций** перечисляет каждый токен, который вы сейчас держите:

- **Актив** — токен.
- **Баланс** — сколько вы держите.
- **Цена** — текущая USD-цена токена.
- **Стоимость** — текущая USD-стоимость вашего владения.
- **Действия** — перейти на страницу **trade** токена или открыть **PnL-карточку**, чтобы поделиться позицией (см. [Приглашайте друзей и рефералы](/ru/protocol/referrals) о том, как ссылки, которыми вы делитесь, несут ваш код приглашения).

Отдельный список показывает ваши **закрытые позиции** — токены, которые вы полностью продали — с результатом каждой.

Если вы пока ничего не держите, вкладка направит вас исследовать и торговать токены.

---

## Примечания

- Всё выводится из ваших **индексированных ончейн-сделок**, а не из ручного журнала — подключите кошелёк, и история заполнится автоматически.
- Список активности — это страница ваших самых недавних сделок, поэтому полная страница не отражает ваш пожизненный итог.
- Только вы видите ярлыки шеринга и торговли в своём профиле; посетители видят ту же сводку результатов и владения для любого кошелька, который открывают.
