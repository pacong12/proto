# Дивиденды холдеров и вестинг

Вкладка **Dividends** в вашем профиле — место, где собираются два типа ончейн-вознаграждений: **дивиденды от разделения комиссий для холдеров** по токенам, которые вы держите, и **вестируемые токены** из распределений, которые разблокируются со временем. Оба получаются напрямую в ваш кошелёк.

---

## Дивиденды холдеров

Некоторые токены включают **Holder Fee Sharing** при запуске. Для таких токенов часть торговых комиссий накапливается **пропорционально всем холдерам**, а не только создателю.

На вкладке Dividends вы увидите:

- **Total claimable** — ваши накопленные вознаграждения, перечисленные по валюте (ETH / WETH на Robinhood, USDC на Arc).
- **Записи по токенам** — каждый токен, который вы держите и который делит комиссии, с ожидающей вас суммой.
- **Claim all** — соберите дивиденды по всем токенам сразу или получите один токен из его строки.

Вознаграждения продолжают накапливаться, пока токен торгуется; получение сметает накопленное в ваш кошелёк. Токен появляется здесь, только если его создатель включил Holder Fee Sharing — см. [Комиссии и вознаграждения создателя](/ru/protocol/fees-and-burns) о том, как настраивается разделение комиссий.

---

## Вестинг

Когда токен выдаёт вам распределение, разблокирующееся со временем (например, распределение создателя или участника), его **график вестинга** показывается на той же вкладке, по токенам:

| Поле                          | Значение                                              |
| :---------------------------- | :---------------------------------------------------- |
| **Total (ещё заблокировано)** | Токены, ещё не разблокированные                       |
| **Claimed**                   | Токены, которые вы уже вывели в кошелёк               |
| **Claimable**                 | Разблокированные токены, которые можно вывести сейчас |
| **Cliff ends**                | Дата, до которой ничего не разблокируется             |
| **Fully unlocked**            | Дата, когда всё распределение завершит вестинг        |

У графика есть **cliff** (до этой даты ничего не высвобождается), затем он разблокируется постепенно до полного вестинга. Для вестинг-позиции доступны два действия:

- **Claim tokens** — высвободите в кошелёк разблокированные токены, доступные к получению сейчас.
- **Claim dividends** — соберите дивиденды от разделения комиссий холдеров, заработанные этой вестинг-позицией.

---

## Примечания

- Всё здесь **ончейн**. Получение — это транзакция кошелька; логика вестинга и разделения комиссий живёт в контрактах токена, и нет администратора, способного перенаправить ваши вознаграждения.
- Вкладка показывает ваши доступные к получению суммы и вестинг только в **вашем** профиле (подключите кошелёк). Суммы обновляются по мере торговли токенов и прохождения разблокировками своего cliff.
