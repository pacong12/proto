# Аналитика протокола

Страница **Analytics** даёт живой, общесетевой обзор активности в Goton — сколько торгуется, сколько токенов запускается и какие комиссии генерирует протокол — для сети, в которой вы сейчас находитесь.

---

## Основной график

Один интерактивный график строит одну метрику за **последние 24 часа**, по интервалам. Переключайте метрику:

| Метрика      | Что строит                                    |
| :----------- | :-------------------------------------------- |
| **Volume**   | Объём торгов во времени                       |
| **Launches** | Запущенные токены во времени                  |
| **Fees**     | Сгенерированные комиссии протокола во времени |

Переключайтесь между видом **сглаженной области** и **столбцов**. Всё ограничено **активной сетью** (Robinhood или Arc) — смените сеть в заголовке, чтобы увидеть числа другой сети.

---

## Ключевые показатели

Под графиком сводные карточки показывают итоги сети, включая:

- **Общий объём торгов** — общий объём в сети.
- **Всего запущено токенов** — сколько токенов создано.
- **Оценка налогов / комиссий** — оценка сгенерированных комиссий.
- **Buyback** — активность выкупа протокола, когда она есть.

Список **топ-токенов** ранжирует токены по капитализации, чтобы вы могли перейти напрямую от макрообзора к странице trade конкретного токена.

---

## Примечания

- Числа строятся из **ончейн-данных** и обновляются по мере обработки новых блоков. Хотите те же числа для своего инструмента? Они в [Публичном API](/integration/api).
- Аналитика **по сети**: страница всегда отражает сеть, показанную в заголовке, и указывает это в примечании об охвате.
- Числа выводятся индексатором и обновляются по мере обработки новых блоков; 24-часовое окно — это скользящий вид, а не календарный день.
