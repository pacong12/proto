# Репутация создателя

Каждый профиль показывает **историю запусков** создателя — быстрый, выведенный ончейн обзор того, что он выпустил. Это помогает трейдерам судить о новом токене по истории кошелька за ним.

---

## Что показывает

Карточка репутации в профиле создателя обобщает каждый токен, который запустил этот кошелёк:

| Метрика              | Значение                                                                        |
| :------------------- | :------------------------------------------------------------------------------ |
| **Launches**         | Сколько токенов создал кошелёк                                                  |
| **Graduated**        | Сколько из них завершили bonding curve и перешли в пул Uniswap v4               |
| **Active**           | Сколько всё ещё активны и торгуются                                             |
| **Graduation rate**  | Graduated ÷ launches, в процентах                                               |
| **Total market cap** | Суммарная USD-капитализация токенов создателя                                   |
| **Top token**        | Крупнейший токен создателя по капитализации, с именем, тикером и капитализацией |

---

## Как это считается

- Числа строятся из **ончейн-данных** — токенов, которые развернул кошелёк, и их текущего рыночного состояния — а не из того, что создатель вводит.
- **Здесь нет самоотчётности.** Создатель не может редактировать эти числа; они отражают запуски, привязанные к адресу.
- Что-то разрабатываете? Те же числа доступны через [Публичный API](/integration/api).

---

## Как читать как трейдер

- Высокий **процент выпуска** по нескольким запускам — более сильный сигнал, чем один выпущенный токен.
- Кошелёк с множеством запусков, но малым числом выпущенных или активных, имеет историю заглохших токенов — стоит взвесить перед покупкой.
- Репутация — это один вход, а не гарантия. Всегда сочетайте её с ликвидностью токена, холдерами и примечаниями о безопасности в [Руководстве по торговле](/ru/protocol/trading-guide).
